Puce d'encodage

Puce intégrée indisponible : aucun encodeur AMF (AMD) ou QSV (Intel) n'a passé le test sur ce PC.

Automatique = carte graphique. NVENC est déjà une puce séparée des cœurs qui font tourner le jeu (impact typique 1–3 % de FPS). La puce intégrée libère NVENC mais coûte environ 6 % de processeur et de la bande passante mémoire. Si votre jeu est limité par le processeur, restez sur la carte graphique.

Mode étiré (4:3 étiré)

Si vous jouez en 1440×1080 étiré, le clip est élargi pour ressembler à ce que vous voyez. Lisible partout (Discord, YouTube).

Coût processeur. L'étirement redimensionne chaque image sur le processeur.

Limites connues5
  • La barre et les statistiques sont invisibles en plein écran exclusif. Si le jeu capture la souris, utilisez les raccourcis : ils marchent toujours.
  • Le buffer écrit environ sur le disque du buffer, en boucle.
  • Les FPS de l'overlay demandent les droits administrateur.
  • Une résolution autre que celle de l'écran passe par un redimensionnement processeur.
  • PC hybride : si l'écran est branché sur la puce intégrée, l'encodage NVIDIA sans copie peut échouer ; Clipper bascule alors seul.

Clipper n'utilise que des API Windows publiques (comme OBS ou Discord) et ne touche jamais au processus du jeu. Personne ne peut garantir l'absence de ban : chaque éditeur décide seul.
